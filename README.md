# 欲求の4タイプ性格診断アプリ (人生の法則)

岡田斗司夫氏の人間関係理論・名著『人生の法則 「欲求の4タイプ」で分かるあなたと他人』および解説動画に基づいた、**10問の質問（Yes / No / 分からない の3択）**で人間の本質的な欲求タイプを判定するWebアプリケーションです。

---

## 🌟 欲求の4タイプとは？

人間を無意識のうちに突き動かしている行動原理や根本的な欲求を、**「外向的／内向的」**と**「具体的／抽象的」**の2軸で4つに分類したフレームワークです。

```
                    【外向的（他者・社会志向）】
                              │
          🌟 注目型           │          👑 司令型
      （外向的 × 抽象的）     │      （外向的 × 具体的）
    ・好かれたい、愛されたい  │    ・勝ちたい、結果を出したい
    ・感情の共有・人気者      │    ・序列重視・リーダーシップ
                              │
  ────────────────────────────┼────────────────────────────
  【抽象的（美学・感情）】   │   【具体的（成果・データ）】
                              │
          🎨 理想型           │          🔬 法則型
      （内向的 × 抽象的）     │      （内向的 × 具体的）
    ・こだわりを貫きたい      │    ・仕組みを知りたい
    ・自己納得・職人肌        │    ・合理的・自由な観察者
                              │
                    【内向的（自己・内面志向）】
```

### 4つのタイプの特徴

1. **👑 司令型 (Commander)**: 「勝ちたい」「成果を出したい」
   - 目標達成力、リーダーシップ、序列や実利を愛するリアリスト。
   - 代表例：織田信長、孫正義、本田圭佑
2. **🌟 注目型 (Attention)**: 「好かれたい」「注目されたい」
   - 人を惹きつける愛嬌、共感力、場の空気を温めるムードメーカー。
   - 代表例：坂本龍馬、明石家さんま、ルフィ
3. **🎨 理想型 (Idealist)**: 「こだわりを貫きたい」「納得したい」
   - 独自の美学や完成度を追求する職人・求道者。
   - 代表例：宮崎駿、イチロー、手塚治虫、スティーブ・ジョブズ
4. **🔬 法則型 (Analyst)**: 「仕組みを知りたい」「自由でいたい」
   - 感情に流されず客観的に因果関係を解き明かす冷静沈着な参謀。
   - 代表例：タモリ、野村克也、ひろゆき、養老孟司

## 🔄 4タイプ人間関係力学（相性マップ）

4タイプの間には、心理的な引力（憧れ）と反発（軽視・天敵）のサイクルが存在します。

* **💖 憧れ（時計回りサイクル）**:
  - `注目型` $\rightarrow$ `司令型` に憧れる（圧倒的な決断力と推進力）
  - `司令型` $\rightarrow$ `法則型` に憧れる（冷静沈着な知性と仕組み化）
  - `法則型` $\rightarrow$ `理想型` に憧れる（損得を超えて己の道を行く熱情）
  - `理想型` $\rightarrow$ `注目型` に憧れる（誰からも自然体で愛される魅力）
* **😒 軽視（反時計回り）**:
  - `司令型` は `注目型` を軽視（ノリだけで中身がない）
  - `注目型` は `理想型` を軽視（殻に閉じこもって頑固）
  - `理想型` は `法則型` を軽視（理屈ばかりで情熱がない）
  - `法則型` は `司令型` を軽視（力技や権力に頼る）
* **⚡ 対角線の天敵（最も理解し合えない関係）**:
  - `司令型` $\leftrightarrow$ `理想型`（成果・勝敗 vs こだわり・美学）
  - `注目型` $\leftrightarrow$ `法則型`（情緒・ノリ vs 冷静・理屈）

## 🚀 アプリの使い方・起動方法

本アプリは外部ライブラリへの依存がなく、モダンなブラウザがあればそのまま動作します。

### 1. 最も簡単な方法（ファイルを直接開く）
`index.html` ファイルをダブルクリックするか、Google Chrome、Safari、EdgeなどのWebブラウザにドラッグ＆ドロップして開いてください。

### 2. ローカルサーバーを立ち上げて開く場合
ターミナルで本ディレクトリに移動し、以下のコマンドを実行します：

```bash
# Pythonの簡易サーバーを起動
python3 -m http.server 8000
```

その後、ブラウザで [http://localhost:8000](http://localhost:8000) にアクセスしてください。

## 📱 機能一覧

- **10問の質問ウィザード**（「はい」「いいえ」「分からない」の3択）
- **プログレスバー＆ステップ表示**
- **前の質問に戻る機能**
- **診断結果の多角的可視化**:
  - メインタイプの判定・キャッチコピー・タグ
  - サブタイプ（第2の傾向）のパーセンテージ算出
  - **4象限マトリクスCanvas**: あなたの欲求位置をリアルタイムにプロット（YOUピン）
  - **スコアレーダーチャート＆バーグラフ**: 4要素のバランス表示
  - 詳細解説（根本欲求・強み・弱み・モチベーション・地雷・有名人の例）
  - **4タイプ相性力学マップ**: 憧れ・憧れられ・見下し・対角線天敵
- **ワンクリック結果テキストコピー**（SNSやメモ帳への貼り付けに最適）
- **𝕏 (旧Twitter) シェアボタン**
- **レスポンシブデザイン**（スマホ・タブレット・PC完全対応）
